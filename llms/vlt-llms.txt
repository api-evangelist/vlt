# vlt

> vlt (pronounced "volt") is a JavaScript package management company started by the creator of npm and former npm core team members, backed by Accel. It ships the open source vlt package manager CLI, the npm-compatible vlt serverless registry (vsr) for Cloudflare's edge, and a hosted registry platform at vlt.io. The hosted registry API at registry.vlt.io is npm-compatible and authentication-gated; self-hosted vsr instances serve an OpenAPI document at /-/api and an interactive reference at /-/docs.

## APIs

- [vlt Serverless Registry (vsr)](https://github.com/vltpkg/vsr): npm-compatible package registry API - publish/install, packuments, tarballs, dist-tags, users, tokens, granular access, search, audit, ping
